# 📅 Daily Agenda Web App (AGENDA.SYS)

Aplikasi web manajemen agenda kegiatan harian yang ringan, responsif, dan kaya fitur. Dirancang untuk membantu pengguna mencatat, memprioritaskan, serta melacak jadwal harian secara efisien dengan tampilan antarmuka *modern geometric grid*.

---

## ✨ Fitur Utama

* **Pengurutan Otomatis (Smart Ordering)**: Agenda otomatis terurut berdasarkan waktu pelaksanaan paling dekat.
* **Manajemen Status & Aksi**: Fitur untuk menandai agenda sebagai **Selesai** (*strike-through effect*) atau menghapus agenda dari daftar.
* **Statistik Agenda**: Dashboard ringkas untuk memantau total agenda, agenda mendatang, dan agenda yang telah terlaksana.
* **Desain Geometric Grid**: Tampilan visual bersih berbasis pola *blueprint grid*.
* **Validasi Ganda (Double Validation)**: Proteksi pengisian form di sisi klien (*client-side* via jQuery) dan sisi server (*server-side* via PHP).
* **Fitur Anti-Duplikasi & Clean URL**: Implementasi pola PRG (*Post/Redirect/Get*) serta pembersihan parameter URL otomatis saat halaman di-refresh.

---

## 🛠️ Tumpukan Teknologi (Tech Stack)

* **Backend**: PHP 8 (MySQLi & Prepared Statements)
* **Database**: MySQL / MariaDB
* **Frontend**: HTML5, CSS3 Kustom (Geometric Blueprint Theme), Bootstrap 5.3
* **Interaktivitas**: JavaScript & jQuery 3.7.1
* **Ikon**: Bootstrap Icons
